# Simon Says Game 🎮

A simple **Simon Says game** implemented using **HTML, CSS, and JavaScript**.  
Test your memory skills by remembering and repeating the sequence of colors generated by the game.

## Features

- Randomly generated color sequences.  
- Incremental levels with increasing difficulty.  
- Sound effects for each color.  
- Visual feedback when buttons are clicked.  
- Game over detection and restart option.  

---

## Technologies

- **HTML5** - Game layout and structure  
- **CSS3** - Styling, animations, and transitions  
- **JavaScript** - Game logic, event handling, and sequence generation
